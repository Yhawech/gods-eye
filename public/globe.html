God's Eye View Integration

3D geospatial command view

This launches the open-source God's Eye View globe beside your GOD EYE intelligence dashboard. Use it for aircraft, vessels, satellites, fires, cameras, terrain, and tactical map context.

Checking Open Globe Console
Local Setup

Run beside GOD EYE

Main GOD EYE runs on port 4173. The 3D globe companion runs on port 4174. Use start:full after setup to launch both together.

npm run setup:globe
npm run install:globe
npm run start:globe
npm run start:full
