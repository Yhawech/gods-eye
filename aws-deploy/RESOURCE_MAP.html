3 · The Final Park → Wake → Park Runbook

1 WAKE — bring everything live (~15 min, ≈$2.50 of credits)

  • Easiest: open github.com/Yhawech/GODS_EYE_LATEST → Actions → Wake GOD EYE (start stack) → Run workflow → Run.
  • Or in a terminal: bash aws-deploy/start-everything.sh
  • What it does: recreates NAT (same EIP → Atlas still valid) → recreates ALB + both listeners → boots 1 instance → auto-installs CodeDeploy agent → auto-deploys the latest stored revision from S3 → waits green → prints the new Dashboard / Globe / Health URLs (the Actions run summary shows them too).
  • The ALB URL changes on every wake — always use the URL the run prints; update your bookmark.

2 (only if you changed code) DEPLOY the new code (~5–10 min)

  • Push your changes to main, then: Actions → GOD EYE AWS ASG CodeDeploy → Run workflow → tick deploy_to_aws=true → Run. (The wake step only redeploys the last stored revision; this ships fresh code.)

3 VERIFY it is live (2 min)

  • Open the Health URL → must show "ok": true and "connected": true.
  • Open the Dashboard URL → main dashboard loads; /v2.html analytics; /traffic.html aviation.
  • Open the Globe URL (port 8080) → globe page loads (photorealistic tiles need your Google Maps billing active).
  • Do this 3–4 days before the viva so the dashboard accumulates real live-feed data.

4 PARK — stop all billing (~3–5 min)

  • Actions → Park GOD EYE (stop billing) → Run workflow. Or: bash aws-deploy/stop-everything.sh
  • What it does: scales the ASG to 0 (instances + disks deleted — no data loss, code comes from S3, data lives in Atlas) → deletes ALB → deletes NAT → keeps the EIP, VPC, IAM, S3, CodeDeploy app → disables alarm actions (no false alarms).
  • Afterwards the EC2 console shows no running instances — that is correct and expected.
Cost rule of thumb: Awake ≈ $77/month · Parked ≈ $3.65/month · each wake/park cycle costs a couple of dollars of partial-day credit. $200 credits = entire semester with park/wake discipline.
