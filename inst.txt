# GOD EYE v2 Threat Intelligence Correlation Platform

A cloud-ready OSINT web application for monitoring geopolitical reporting, military-related reporting, economic risk, cyber incidents, earthquakes, fires, severe weather, natural disasters, live aviation, and incident intelligence reports.

The v2 upgrade moves the API layer to FastAPI, stores live results in MongoDB Atlas, builds history/trend views, saves analyst reports, exports PDF intelligence reports, and includes a DeepSeek-ready analyst chatbot for open-source incident analysis.

## Run

```powershell
npm start
```

Then open:

```text
http://localhost:4173
```

Open:

- Main dashboard: `http://localhost:4173`
- Threat intelligence v2: `http://localhost:4173/v2.html`
- Live aviation: `http://localhost:4173/traffic.html`

## Optional AI API Key

The analyst chatbot and report builder work without an AI key using a local rule-based fallback. For stronger AI-generated analysis, set your DeepSeek API key before starting:

```powershell
$env:DEEPSEEK_API_KEY="your-deepseek-api-key"
$env:DEEPSEEK_MODEL="deepseek-v4-flash"
npm start

OR set by 
setx
```

`DEEPSEEK_MODEL` is optional. You can use `deepseek-v4-pro` for heavier reasoning.

## MongoDB Atlas

MongoDB is required for saved events, chat history, and intelligence reports. Set these before starting locally:

```powershell
$env:MONGODB_URI="mongodb+srv://USER:PASSWORD@YOUR_CLUSTER.mongodb.net/?retryWrites=true&w=majority"
$env:MONGODB_DB="gods_eye"
npm start
```
Two things happened:

1. `setx` only works in **new terminal windows**, so current cmd will still show `%MONGODB_URI%`.
2. Your MongoDB command has a small mistake: you saved the value as `MONGODB_URI=mongodb+srv://...` inside the variable. It should start directly with `mongodb+srv://...`.

Fix it like this in **cmd**:

```cmd
setx MONGODB_URI "mongodb+srv://USER:PASSWORD@YOUR_CLUSTER.mongodb.net/gods_eye?retryWrites=true&w=majority&appName=gods-eye-cluster"
setx MONGODB_DB "gods_eye"
setx DEEPSEEK_API_KEY "YOUR_DEEPSEEK_KEY"
```

Then **close cmd completely**, open a new cmd, and check:

```cmd
echo %MONGODB_URI%
echo %MONGODB_DB%
echo %DEEPSEEK_API_KEY%
```

OR

```cmd
set MONGODB_URI
set MONGODB_DB
set DEEPSEEK_API_KEY

Then run:

```cmd
cd /d C:\Users\racha\OneDrive\Documents\OSINT-2
npm start
```

Also: since you pasted real-looking keys here, rotate/regenerate the DeepSeek key and MongoDB password later before final deployment. Better safe.

For AWS deployment, add `MONGODB_URI` as a GitHub Actions secret and `MONGODB_DB` as an optional GitHub Actions variable.

## Live Sources

- USGS earthquake GeoJSON feeds
- NASA EONET active natural events
- NOAA/NWS active alerts
- GDACS disaster RSS
- Defense.gov RSS
- FEMA updates RSS
- Google News RSS
- Google News economic, cyber, energy, geopolitical, and military searches
- GDELT 2.1 Document API for geopolitical, military, economic, cyber, and disaster-related reporting
- Shadowbroker-inspired source pack: BBC, NPR, Al Jazeera, Guardian, The War Zone, Bellingcat, Defense News, The Diplomat, SCMP, Yonhap, Asia Times, France 24, and DW RSS feeds
- OpenSky Network aircraft states
- Airplanes.live military aviation

The dashboard refreshes every 5 minutes by default. The FastAPI backend caches live event refreshes, stores events, chat messages, and analyst reports in MongoDB Atlas, and keeps retrying sources that temporarily fail.

## Shadowbroker Source Pack

This project includes a native GOD EYE source-pack integration inspired by [BigBodyCobain/Shadowbroker](https://github.com/BigBodyCobain/Shadowbroker). It is not a separate Next.js app inside this repo; the useful OSINT feeds and source-attribution ideas are adapted into the existing FastAPI refresh pipeline so they work with GOD EYE reports, MongoDB storage, PDF exports, and the DeepSeek analyst chatbot.

Endpoint:

```text
/api/v2/shadowbroker
```

No new API key is required for the imported source pack. Optional paid/heavy Shadowbroker-style layers such as Shodan, AISStream, Sentinel Hub, CCTV, scanners, and mesh communications are intentionally not enabled by default.

Important MongoDB collections:

- `events` - stored OSINT events from live feeds
- `analyst_reports` - generated incident/situation reports and PDF report source data
- `chat_messages` - analyst chatbot history
- `ioc_lookups` - optional legacy IOC lookup history

The old Node server is still available with:

```powershell
npm run start:node
```
